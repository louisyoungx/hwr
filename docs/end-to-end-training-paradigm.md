# 端到端视觉—语言—动作训练范式

> 状态：当前训练架构决策，后续训练实现以本文为准
>
> 适用范围：三维仿真、本机训练、未来真机数据与部署

## 1. 结论

平台训练一个从视觉、自然语言和机器人本体状态直接产生连续动作的策略：

```text
同步后的多相机数据 ──> 视觉预处理 ──┐
自然语言指令 ────────> 文本编码 ─────┼─> 融合策略 ─> 未来一段连续动作 ─> 独立安全过滤 ─> 仿真/真机
机器人本体状态 ──────────────────────┘
```

策略内部可以学习空间关系和时间结构，但平台不在策略前面构造对象 token、目标 token、技能名称或人工任务计划。训练样本也不要求人为标注“找到、接近、抓取、放置”等阶段。

底盘和双臂属于同一个动作空间。部署时只运行策略、视觉预处理和独立安全层；训练期使用的仿真真值、专家状态和 critic 不得进入部署策略输入。

## 2. 模块边界

### 2.1 策略可见输入

Actor 只能接收：

- 经过确定性预处理的头部相机 RGB-D 及有效性信息；
- 腕部相机的局部高分辨率视觉及有效性信息；
- 最近若干帧视觉历史；
- 原始自然语言指令经本地文本编码器产生的向量；
- 底盘、双臂、夹爪的关节状态和最近实际执行动作；
- 传感器时间戳、丢帧掩码等不包含任务答案的质量信息。

以下信息禁止进入 Actor：

- 仿真物体位姿、目标位姿、接触真值和成功标志；
- 专家阶段、脚本状态、任务进度和未来动作；
- 对象 ID、目标 ID、人工技能计划或符号解析结果；
- 仅仿真可获得、真机无法复现的任何字段。

### 2.2 策略输出

Actor 一次预测未来若干控制步的动作块，至少覆盖：

- 底盘线速度和角速度；
- 左、右机械臂的关节增量或末端位姿增量；
- 左、右夹爪目标；
- 动作块的有效长度或停止概率。

动作块缓解单步控制抖动并允许模型学习短期动作一致性。执行器限制、碰撞急停、速度和力矩约束由策略外的安全层强制执行，不能靠训练损失替代。

### 2.3 依赖方向

- 核心层只定义相机帧、预处理视觉、本体状态、语言指令、动作块和 Episode 契约；
- 视觉、语言、策略和训练模块依赖核心契约；
- MuJoCo、真实相机、机械臂 SDK 和模型库只在适配器中出现；
- 仿真与真机必须调用同一个视觉预处理接口并产生同一种 ActorObservation；
- 安全过滤独立于学习策略，既不导入训练器，也不被策略绕过。

## 3. 视觉预处理

视觉不是把原始图像直接缩放后交给网络。预处理分为确定性传感器处理和可学习视觉前端，两者分别测试、保存配置和记录版本。

### 3.1 确定性传感器处理

每个 Episode 保留未经覆盖的原始帧、标定参数和时间戳；策略输入由下列步骤派生：

1. 多相机与机器人状态按时间窗口同步，并产生缺失掩码；
2. 使用相机内外参去畸变并将 RGB、深度对齐；
3. 清除非法深度、孤立噪点和超出工作空间的点，保留有效性掩码；
4. 将深度转换到统一机器人坐标系，构建稀疏点云或等价的三维视觉表示；
5. 对头部全局视野和腕部局部视野分别裁剪、缩放和归一化；
6. 组合短时历史，显式标记重复帧、丢帧和相机不可用状态。

预处理参数是 checkpoint 的组成部分。训练、闭环评测和未来真机部署必须加载同一份参数，禁止在评测时临时改变裁剪、归一化或坐标系。

### 3.2 可学习视觉前端

首选表示是头部 RGB-D 的三维全局特征与腕部相机的二维局部细节融合，而不是依赖真值分割。视觉前端随 Actor 联合训练，并可使用以下辅助目标提高样本效率：

- 深度重建和时序一致性；
- 由仿真标签监督的实例分割与可操作区域预测；
- 跨视角和跨时间对比学习；
- 机器人自身遮挡区域和相机运动预测。

这些输出只作为潜在特征或训练辅助损失，不形成部署时的符号任务计划。仿真分割、材质 ID 和物体位姿只能作为监督标签，不能回流到 Actor 输入。

### 3.3 视觉随机化

训练期间对相机外参小扰动、曝光、白平衡、运动模糊、深度空洞、材质、光照和遮挡做可复现随机化。验证集与隐藏评测集使用独立种子，且随机化参数进入运行清单。

## 4. 自然语言先验

先验知识来自可在本机运行的预训练文本编码器，而不是手写指令解析器：

- 首阶段冻结文本编码器，利用其已有的中文语义相似性；
- 每个家务意图配多种自然表达，但不配符号动作序列；
- 通过“指令、视觉轨迹、实际动作、最终奖励”的配对建立语言到环境行为的落地关系；
- 数据量足够后只微调文本编码器上层或使用低秩适配，避免小数据破坏语言先验；
- 编码器权重、分词器和哈希随 checkpoint 登记，训练和部署不依赖在线服务。

语言相似性只能提供先验。某个词在当前家庭场景中对应什么视觉现象、怎样操作以及操作是否成功，必须从轨迹和环境反馈中学习。

## 5. 学习流程

### 5.1 行为克隆预热

先使用成功的仿真轨迹、人工遥操作轨迹以及后续真机轨迹训练动作块 Actor。仿真专家可以使用特权状态来产生示范，但特权字段不写入 Actor 张量。

行为克隆只负责让随机策略进入可探索区域，不作为最终训练终点。闭环成功率而非离线动作误差决定是否进入下一阶段。

### 5.2 非对称 Actor-Critic 强化学习

行为克隆 checkpoint 作为初始化，在仿真中继续强化学习：

- Actor 始终只看第 2.1 节的可部署输入；
- 训练期 critic 可以读取物体位姿、接触、目标状态和完整机器人状态；
- 奖励由任务最终状态、进展、碰撞、安全和动作平滑度计算；
- critic、奖励计算和仿真真值在导出部署 checkpoint 时移除；
- 训练同时采样简单布局、随机化布局和历史失败状态，逐步扩大难度。

这种非对称结构用仿真真值降低价值估计难度，同时保持 Actor 的 sim-to-real 输入边界。任务可以使用环境真值判定成功，但不能把判定过程改写为 Actor 前置规则。

### 5.3 失败回流

失败 Episode 原样进入可追踪 replay buffer，并按碰撞、未抓稳、视觉丢失、超时等训练标签分层采样。标签只影响采样和诊断，不转换成部署规则，也不作为 Actor 输入。

每轮训练按以下闭环执行：

```text
采集/回放 -> 视觉预处理 -> BC 更新 -> 仿真 RL 更新 -> checkpoint 保存并重载
           ^                                      |
           └────── 隐藏种子失败 Episode 回流 ─────┘
```

## 6. 本机训练与可复现性

全部训练必须能在现有本机完成，不依赖远程推理 API。训练器可自动选择 MPS、CUDA 或 CPU，并必须：

- 保存数据 manifest、预处理配置、文本编码器标识、模型配置、随机种子和代码提交；
- 周期保存 Actor、critic、优化器和 replay buffer 状态，支持中断续训；
- 导出不含 critic 和特权字段的部署 checkpoint；
- 从磁盘重载部署 checkpoint 后执行闭环评测；
- 按 Episode、布局、物体实例和随机化种子隔离训练与评测数据。

## 7. 当前实施顺序

1. 定义原始相机包、预处理视觉、自然语言指令和动作块的数据契约；
2. 实现确定性 RGB-D 预处理与审计，保证仿真和未来真机复用；
3. 将现有成功轨迹重采为不含阶段标签和目标 ID 的端到端数据；
4. 训练视觉—语言—动作分块 Actor 并完成保存、重载和闭环；
5. 加入 privileged critic，在三类家务场景中进行本机强化学习；
6. 每个场景用至少 20 个未见种子评测，回流失败并继续训练；
7. 生成未经剪辑的复现视频和输入字段审计报告。

## 8. 阶段验收

一个训练阶段只有同时满足以下条件才算完成：

- 自动化测试证明 Actor 输入不存在特权字段和人工阶段/技能字段；
- 同一原始观测经相同配置得到确定一致的预处理结果；
- checkpoint 包含并校验视觉预处理与文本编码器版本；
- 部署 checkpoint 能在没有 critic、专家或任务脚本的进程中运行；
- checkpoint 从磁盘重载后，在隔离种子上执行闭环动作；
- 视频、Episode、模型哈希、代码提交和配置能够相互追溯。

离线损失下降、专家脚本成功或少量训练种子回放均不构成家务训练完成证据。
